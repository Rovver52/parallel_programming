## Описание проекта
Данная работа посвящена реализации параллельного алгоритма умножения квадратных матриц с использованием технологии MPI (Message Passing Interface).
### Цели работы
1. Модифицировать последовательный алгоритм умножения матриц для распределённых вычислений
2. Реализовать распараллеливание по строкам матрицы с использованием коллективных операций MPI
3. Провести эксперименты с варьированием размера матриц и количества процессов
4. Оценить эффективность параллелизации по метрикам: время, ускорение, эффективность, производительность

### Алгоритм:
1. Матрица A разбивается по строкам между процессами
2. Матрица B рассылается всем процессам через MPI_Bcast
3. Каждый процесс вычисляет свою часть результирующей матрицы C
4. Результаты собираются на процессе 0 через MPI_Gatherv

# Структура файлов
- `matrix_mult_omp.cpp` - Исходный код программы на C++ с использованием MPI. Реализует чтение матриц, параллельное умножение, запись результата и замер времени
- `generate.py`- Скрипт генерации тестовых матриц с псевдослучайными значениями
- `run_mpi_tests.py` - Скрипт автоматического запуска серии экспериментов с разными размерами и количеством процессов
- `verify_mpi.py` - Скрипт верификации результатов через сравнение с numpy.dot()
- `plot_mpi_results.py` - Скрипт построения графиков зависимости времени, ускорения и эффективности
- `mpi_statistics.csv` - Результаты экспериментов (данный файл)

### Наблюдения
1. Для малых матриц (200×200) лучшее время на 8 процессах, но эффективность низкая (38%)
2. Для средних матриц (400-1600) оптимально 4 процесса с эффективностью 50-78%
3. Для больших матриц (2000×2000) 4 и 8 процессов показывают почти одинаковое время
4. При 8 процессах эффективность падает до 22-38% из-за накладных расходов на коммуникации MPI

## Выводы по графикам
1. Оптимальная конфигурация
Для данной системы и задачи оптимально использовать 2-4 процесса MPI:
● Эффективность: 70-98%
● Ускорение: 1.5-3.1×
● Хороший баланс между скоростью и использованием ресурсов
2. Ограничения масштабируемости
● Коммуникационные расходы: MPI_Bcast и MPI_Gatherv требуют передачи больших объемов данных
● Последовательная часть: ~6-10% кода не распараллелено (закон Амдала)
● Конкуренция за ресурсы: 8 процессов на одном узле создают contention памяти и сети

Реализованная программа демонстрирует хорошее ускорение (до 3×) для задач среднего и большого размера при использовании 4 процессов MPI, что делает её применимой для реальных вычислений на многопроцессорных системах.

# Общий вывод по лабораторной работе
Разработанная параллельная программа умножения матриц с использованием MPI демонстрирует устойчивое ускорение до 3.14× при использовании 4 процессов для задач среднего и большого размера. Эффективность параллелизации ограничена накладными расходами на межпроцессное взаимодействие и последовательными участками кода, что соответствует теоретическим ожиданиям (закон Амдала).
Программа готова к использованию для решения реальных вычислительных задач на многопроцессорных и распределённых системах. Для достижения максимальной производительности рекомендуется подбирать количество процессов в зависимости от размера задачи, ориентируясь на диапазон 2–4 процесса для данной аппаратной конфигурации.
