# Умножение квадратных матриц

## Описание
Лабораторная работа по реализации умножения двух квадратных матриц на языке C++ с автоматизированной верификацией результатов.

## Цель работы
- Реализовать алгоритм умножения квадратных матриц
- Выполнить замер времени выполнения программы
- Рассчитать объем вычислительной задачи
- Провести автоматизированную верификацию результатов с использованием библиотеки NumPy (Python)

## Функциональность
Программа выполняет:
- Чтение исходных матриц из файлов
- Умножение двух квадратных матриц размером N×N
- Запись результирующей матрицы в файл
- Вывод метаданных:
  - Время выполнения (мс)
  - Количество операций (FLOPs)
  - Объем используемой памяти (байты)

## Описание файлов

- `matrix_mult.cpp` - исходный код программы на C++. Реализует умножение матриц, чтение и запись файлов, измерение времени выполнения и объёма вычислений.

- `generate.py` - скрипт на Python для генерации случайных тестовых матриц заданного размера. Создаёт входные файлы для программы.

- `verify.py` - скрипт на Python для автоматической проверки результатов. Сравнивает результат C++ программы с расчётом через NumPy.

- `run_tests.py` - скрипт для автоматического запуска тестов для разных размеров матриц (200, 400, 800, 1200, 1600, 2000) и сбора статистики в файл `matrix_statistics.csv`.

- `matrix_a.txt` - входной файл с первой матрицей, автоматически генерируемый при запуске тестов.

- `matrix_b.txt` - входной файл со второй матрицей, автоматически генерируемый при запуске тестов.

- `result.txt` - выходной файл с результатом умножения. Содержит матрицу-результат, время выполнения, количество операций и объём данных.

- `matrix_statistics.csv` - файл со статистикой производительности. Содержит данные для матриц разных размеров.

- `README.md` - документация проекта.

- ## Требования

### Системные требования
- Операционная система: Windows/Linux/macOS
- Компилятор C++ с поддержкой стандарта C++11 (g++, clang++)
- Python 3.6+
- Библиотека NumPy для Python

- ## Работоспособность программы
### Установка зависимостей
```bash
pip install numpy
```

### Компиляция программы
```bash
g++ -O2 -std=c++11 -o matrix_mult.exe matrix_mult.cpp
```
### Генерация тестовых данных
```bash
python generate.py 100 matrix_a.txt matrix_b.txt
```
### Запуск умножения матриц
```bash
./matrix_mult.exe matrix_a.txt matrix_b.txt result.txt
```
### Верификация результатов
```bash
python verify.py matrix_a.txt matrix_b.txt result.txt
```
### Автоматическое тестирование
```bash
python run_tests.py
```
Скрипт автоматически:
Протестирует матрицы размеров: 200, 400, 800, 1200, 1600, 2000
Соберет статистику производительности
Сохранит результаты в matrix_statistics.csv

## Вывод
В результате выполнения лабораторной работы было установлено, что алгоритм последовательного умножения матриц характеризуется кубической вычислительной сложностью O(n³). При увеличении размера матриц время выполнения возрастает непропорционально быстро, что существенно ограничивает применимость данного подхода для обработки больших объёмов данных. Полученные экспериментальные данные подтверждают целесообразность использования параллельных вычислений и оптимизированных алгоритмов для работы с матрицами большого размера.
