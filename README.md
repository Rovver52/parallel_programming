## 1. Описание проекта
Данная работа посвящена реализации параллельного алгоритма умножения квадратных матриц с использованием технологии MPI (Message Passing Interface) на суперкомпьютере "Сергей Королёв"
### Цели работы
1. Модифицировать последовательный алгоритм умножения матриц для распределённых вычислений
2. Реализовать распараллеливание по строкам матрицы с использованием коллективных операций MPI
3. Провести эксперименты с варьированием размера матриц и количества процессов
4. Оценить эффективность параллелизации по метрикам: время, ускорение, эффективность, производительность

### Алгоритм:
1. Матрица A разбивается по строкам между процессами
2. Матрица B рассылается всем процессам через MPI_Bcast
3. Каждый процесс вычисляет свою часть результирующей матрицы C
4. Результаты собираются на процессе 0 через MPI_Gatherv

## 4. Вывод по показаниям

При увеличении количества процессов, скорость выполненния задачи уменьшается примерно в столько же раз, во сколько увеличивается количество процессов, ~2 раза.
Масштабируемость: с ростом числа процессов время выполнения уменьшается практически обратно пропорционально числу процессов. Для матрицы 2000×2000 ускорение на 4 процессах достигает 3.94 (эффективность 98%).

## 5. Вывод по лабораторной работе

В ходе выполнения лабораторной работы была разработана параллельная программа умножения квадратных матриц с использованием MPI. Программа корректно работает на суперкомпьютере «Сергей Королёв», поддерживает произвольное число процессов и автоматически распределяет строки матрицы A.

Проведённые эксперименты показали:

При увеличении числа процессов время выполнения сокращается почти пропорционально их количеству для задач большого размера.
Цель работы достигнута, программа была успешно запущена на суперкомпьютере.
