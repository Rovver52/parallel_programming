## Описание файлов

- `matrix_mult_omp.cpp` -  исходный код программы на C++ с использованием OpenMP. Реализует чтение матриц из файлов, параллельное умножение матриц с настраиваемым количеством потоков, запись результата в файл и измерение времени выполнения. Содержит функции для чтения/записи матриц, параллельное умножение с директивами #pragma omp parallel for collapse(2), расчёт метаданных (время, FLOPs, количество потоков).

- `generate.py` - скрипт на Python для генерации случайных тестовых матриц заданного размера. Создаёт входные файлы для программы.

- `verify_omp.py` - скрипт для автоматической верификации результатов вычислений. Сравнивает результат работы C++ программы с эталонным вычислением через библиотеку NumPy (numpy.dot()). Выводит максимальное расхождение между матрицами и статус проверки (SUCCESS/FAILED). Использует допуск rtol=1e-5, atol=1e-8 для учёта погрешностей вычислений с плавающей точкой.

- `run_omp_tests.py` - скрипт для автоматического запуска серии экспериментов. Последовательно тестирует различные комбинации размеров матриц (200, 400, 800, 1200, 1600, 2000) и количества потоков (1, 2, 4, 8). Автоматически генерирует входные данные через generate.py, запускает matrix_mult_omp.exe, извлекает метаданные из выходного файла и собирает статистику

- `openmp_statistics.csv` - файл со статистикой экспериментов в формате CSV с разделителем ;. Содержит данные для каждой конфигурации: размер матрицы, количество потоков, время выполнения (сек), количество операций (FLOPS), производительность (GFLOPS), ускорение относительно последовательной версии и эффективность распараллеливания (%). Используется скриптом plot_results.py для построения графиков.

- `plot_results.py` - скрипт для визуализации результатов экспериментов. Читает данные из openmp_statistics.csv (или генерирует тестовые данные если файл отсутствует) и строит графики: зависимости времени выполнения от количества потоков, времени от размера матрицы, эффективности распараллеливания и ускорения относительно идеального. Сохраняет графики в формате PNG с высоким разрешением (300 DPI).
- - ## Требования

### Системные требования
- Операционная система: Windows/Linux/macOS
- Компилятор C++ с поддержкой стандарта C++11 (g++, clang++)
- Python 3.6+
- Библиотека NumPy для Python

- ## Работоспособность программы
- ### Запуск теста 
  ```bash
  python run_omp_tests.py
  ```
  ### Компиляция программы
  ```bash
  g++ -fopenmp -O3 -o matrix_mult_omp.exe matrix_mult_omp.cpp
  ```

### Вывод
Параллельная реализация умножения матриц с использованием OpenMP показала хорошую масштабируемость и эффективность для задач достаточного размера. Достигнутое ускорение соответствует теоретическим ожиданиям с учётом закона Амдала и архитектурных ограничений системы.
