## 2 CUDA (Compute Unified Device Architecture)

CUDA — платформа параллельного программирования от NVIDIA, позволяющая использовать графические процессоры (GPU) для высокопроизводительных вычислений. В отличие от CPU (4-8 ядер), современные GPU содержат тысячи ядер, оптимизированных для параллельной обработки данных.

---

## 3 Описание алгоритма

### 3.1 Распределение данных

При умножении матриц C = A × B на GPU:
- Каждый поток вычисляет **один элемент** результирующей матрицы C
- Матрицы A и B копируются из оперативной памяти в видеопамять (VRAM)
- Результат вычислений копируется обратно в оперативную память

### 3.2 Схема работы

| Этап | Описание |
|------|----------|
| 1 | Чтение матриц A и B из файлов (CPU) |
| 2 | Копирование данных из RAM в VRAM (cudaMemcpy) |
| 3 | Запуск CUDA ядра на GPU |
| 4 | Копирование результата из VRAM в RAM |
| 5 | Сохранение результата в файл |

### 3.3 Конфигурация сетки блоков

Для матрицы размера N×N и размера блока B×B:
- `threadsPerBlock = (B, B)` — количество потоков в блоке
- `blocksPerGrid = (ceil(N/B), ceil(N/B))` — количество блоков в сетке

## 6 Анализ результатов

### 6.1 Анализ времени выполнения

| Размер | Наблюдение |
|--------|------------|
| N=200 | Лучшее время на блоке 32×32 (0.178 с) |
| N=400 | Лучшее время на блоке 16×16 (0.176 с) |
| N=800 | Лучшее время на блоке 32×32 (0.235 с) |
| N=1200 | Лучшее время на блоке 32×32 (0.291 с) |
| N=1600 | Лучшее время на блоке 8×8 (0.355 с) |
| N=2000 | Лучшее время на блоке 8×8 (0.477 с) |

### 6.2 Анализ ускорения

**Ключевые наблюдения:**

**Для малых матриц (N=200-400):**
- Ускорение незначительное (1.2-10×)
- Накладные расходы на копирование данных сопоставимы с временем вычислений

**Для средних матриц (N=800-1200):**
- Ускорение достигает 124×
- Вычислительная работа начинает преобладать над накладными расходами

**Для больших матриц (N=1600-2000):**
- Максимальное ускорение до 662×
- GPU полностью раскрывает свой потенциал


### 6.3 Влияние размера блока

| Размер блока | Преимущества | Недостатки |
|--------------|--------------|-------------|
| 8×8 (64 потока) | Лучше для больших матриц (≥1600) | Меньшая занятость warp |
| 16×16 (256 потоков) | Хороший баланс для средних матриц | Умеренная занятость |
| 32×32 (1024 потока) | Лучше для малых матриц (≤400) | Может превышать лимиты регистров |
